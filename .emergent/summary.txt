<product_requirements>
The platform, NoFeePlaces, is an apartment listing service. The primary product requirement is to provide a reliable and functional user authentication system. Users must be able to sign up and sign in to access key benefits like viewing exact apartment addresses and scheduling showings.

The immediate and most critical problem is that the core sign-in/sign-up functionality is broken for end-users. Specifically, the email/password flow is failing because users cannot type into the password field, and the Google Sign-In flow is non-operational due to OAuth configuration issues.

The development work so far has focused on fixing these authentication issues. After multiple failed patch attempts on the existing complex authentication modal, the strategy shifted to a complete rebuild of the feature. This involved removing all social login options (Google, Apple, Facebook) to create a streamlined, stable email/password-only system as a new baseline. A secondary requirement is to ensure the apartment count displayed on the homepage is accurate and to eventually streamline the existing calendar-based scheduling feature.
</product_requirements>
